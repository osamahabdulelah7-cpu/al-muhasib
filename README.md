# المحاسب — Al-Muhasib

تطبيق Flutter لإدارة الحسابات والمعاملات المالية باللغة العربية، مع واجهة مناسبة للكتابة من اليمين إلى اليسار.

## نبذة عن التطبيق

يهدف **المحاسب** إلى تسهيل تسجيل الحركات المالية ومتابعة الأرصدة وإعداد كشوف الحسابات، مع الاحتفاظ بالبيانات محليًا على الجهاز وتوفير أدوات للتصدير والنسخ الاحتياطي.

## الوظائف الرئيسية

- تسجيل المعاملات المالية وتصنيف المبالغ ضمن **له** و**عليه**.
- عرض كشف الحساب والرصيد الناتج عن الحركات.
- حفظ البيانات محليًا باستخدام SQLite.
- تصدير التقارير إلى PDF وملفات Excel بصيغة XLSX.
- استيراد البيانات من ملفات Excel المدعومة.
- إنشاء النسخ الاحتياطية واستعادة البيانات من النسخ المتاحة.
- دعم خيارات النسخ الاحتياطي المحلي وGoogle Drive والتخزين الخارجي وفق إعدادات الجهاز والتطبيق.
- واجهة عربية وخط Cairo.

> قد يختلف توفر بعض الوظائف حسب إصدار التطبيق وإعدادات الجهاز. يُنصح دائمًا بالاحتفاظ بنسخة احتياطية إضافية قبل استعادة البيانات أو إجراء تغييرات مهمة.

## التقنيات المستخدمة

- **Flutter / Dart** لبناء التطبيق.
- **SQLite** عبر حزمة `sqflite` لتخزين البيانات محليًا.
- **PDF** عبر حزمتي `pdf` و`printing`.
- **Excel** عبر حزمة `excel` لقراءة ملفات XLSX وكتابتها.
- **Google APIs** ومكونات Android اللازمة لوظائف النسخ الاحتياطي والتخزين.

## متطلبات التطوير

بحسب `pubspec.yaml` الحالي:

- Flutter: `>=3.44.0`
- Dart SDK: `>=3.13.0 <4.0.0`

## تشغيل المشروع

بعد تثبيت Flutter وإعداد بيئة Android:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء نسخة Android بصيغة APK:

```bash
flutter build apk --release
```

## ملاحظات مهمة

- اختبر النسخ الاحتياطي والاستعادة على نسخة تجريبية من البيانات قبل الاعتماد على أي استعادة فعلية.
- احتفظ بنسخ احتياطية في مكان آمن، ولا تعتمد على نسخة واحدة فقط.
- لا تعتبر نجاح البناء وحده دليلًا على صحة جميع وظائف التطبيق؛ يجب اختبار التصدير والاستيراد والنسخ الاحتياطي على الجهاز.
